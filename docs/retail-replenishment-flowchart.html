  • Agent: Strands' model-driven loop. Claude picks the tool sequence to keep shelves stocked through tonight without over-ordering.
  • Loop: read shelf velocity, compare with stock on hand, predict tonight's burn rate, and emit a pick list only if a shelf will run dry.
  • Guardrail: blocks orders above shelf max capacity or from SKUs reserved for another store.
  • Outcome: a block means log it and suggest a substitute. A pass means write the pick list to the warehouse system.
  • ML version: EventBridge schedules runs, Kinesis and S3 feed a Glue feature pipeline, a SageMaker model forecasts demand, and Step Functions with Lambda apply reorder-point rules and the same guardrails, with CloudWatch watching drift. It makes the same decision without an LLM; it is cheaper and more predictable per call, but every new signal needs feature work and retraining, while the agent can reason over new tools.
